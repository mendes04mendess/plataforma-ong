# Instituto Esperança — Plataforma Web para ONG

## Sobre o projeto

O Instituto Esperança é uma plataforma web desenvolvida com o objetivo de apresentar projetos sociais, incentivar a participação de voluntários e divulgar formas de contribuição para uma organização não governamental (ONG).

O projeto foi desenvolvido como atividade acadêmica, com foco na construção de páginas web, na organização do conteúdo, na acessibilidade e na adaptação para diferentes tamanhos de tela.

## Objetivos

* Apresentar a instituição e sua missão social.
* Divulgar projetos e ações comunitárias.
* Disponibilizar um formulário de cadastro de voluntários.
* Informar formas de contribuição financeira e doação de alimentos.
* Aplicar conceitos de desenvolvimento web, responsividade e acessibilidade.

## Tecnologias utilizadas

* **HTML5:** estrutura e organização do conteúdo.
* **CSS3:** estilos visuais, layout e responsividade.
* **JavaScript:** interatividade, máscaras de campos e validação do formulário.

## Funcionalidades

* Página inicial com apresentação institucional.
* Página de projetos sociais.
* Formulário de cadastro com campos obrigatórios e formatação de CPF, telefone e CEP.
* Mensagem de confirmação após o envio do formulário.
* Página com informações sobre doações.
* Menu de navegação entre as páginas.
* Layout adaptado para dispositivos móveis.

## Estrutura do projeto

* `index.html` — página inicial.
* `projetos.html` — apresentação dos projetos sociais.
* `cadastro.html` — formulário de cadastro.
* `doacao.html` — informações sobre doações.
* `CSS/style.css` — estilos e responsividade.
* `JS/script.js` — interatividade e formatação dos campos.
* `imagens/` — imagens utilizadas no site.

## Acessibilidade e validação

O projeto utiliza textos alternativos em imagens, rótulos associados aos campos do formulário e indicadores visuais de foco para navegação por teclado.

As quatro páginas HTML foram verificadas pelo W3C Markup Validation Service e passaram sem erros ou avisos.

## Observação sobre o funcionamento

O formulário demonstra validações e uma mensagem de sucesso no navegador. Nesta versão acadêmica, os dados não são armazenados permanentemente em um banco de dados nem enviados para um servidor.

A chave PIX exibida na página de doações é demonstrativa e não deve ser utilizada para realizar pagamentos reais.
